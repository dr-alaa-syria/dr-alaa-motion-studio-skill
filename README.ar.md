# Dr Alaa Motion Studio Skill (ملخص عربي)

قوالب إنتاج قابلة لإعادة الاستخدام للموشن غرافيك: شعار متحرك (مقدمة، ونهاية، ومقطع قصير)، وإعلان منتج، وريل نصّي عربي بكلمة بكلمة، ولقطة منتج 3D. كل قالب يُخرج **16:9 و9:16** من نفس ملف `content.json`. الهوية البصرية في ملف `brand.json` منفصل، فتعمل القوالب مع أي علامة تجارية.

> **الحالة: الإصدار 0.1.0 قيد التحضير.** تم تجهيز الحزمة، لكن خطوات التثبيت والرندر **لم تُختبر بعد على جهاز نظيف**. اقرأ `CHANGELOG.md` قبل الاعتماد عليها.

النسخة الإنجليزية الكاملة: [README.md](README.md)

## المحتوى

| القالب | المحرّك | المخرجات |
|---|---|---|
| `templates/remotion-logo` | Remotion | مقطع تمهيدي (Sting) ومقدمة (Intro) ونهاية (Outro)، بمقاسين |
| `templates/remotion-promo` | Remotion | نسخة قصيرة (حوالي 15 ثانية) وكاملة (حوالي 27 ثانية)، بمقاسين |
| `templates/remotion-kinetic` | Remotion | ريل عربي بكلمة بكلمة، والكلمة المهمة مميزة |
| `templates/blender-product` | Blender (Eevee) | لقطة منتج بثلاث حركات كاميرا، تُركّب في إعلان Remotion |

## المتطلبات (ويندوز 11 64 بت، للإصدار 0.1.0)

تثبّت هذه الأدوات بنفسك، ولا تُرفق مع المستودع. التفاصيل في [docs/INSTALL.ar.md](docs/INSTALL.ar.md).

- Python 3.12 مع numpy.
- Node.js (اختُبر الإصدار v26.13.0 فقط).
- FFmpeg و ffprobe في متغير PATH.
- Google Chrome أو Chromium (للرندر).
- Blender 5.3.0 (اختياري، لقالب المنتج فقط، واختُبر هذا الإصدار فقط).

## Generated assets

Sound effects and the music bed are generated by code in this repository, using numpy only. No sample library is used, so they carry no third-party license. The generated files are not stored in the repository.

## Excluded from this repository

- Brand logos, brand fonts, brand guidelines, and contact details that belong to any specific client or organization.
- Fonts with unclear redistribution terms, such as Dubai (bundled with Windows).
- Rendered videos, exports, and personal project files.
- Remotion, FFmpeg, Blender, and Chrome binaries.
